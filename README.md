# News Headline Scraper

Collects the front-page headlines from Hacker News and saves them to a CSV file.

## Tech
Python, requests, BeautifulSoup

## Run it
```
pip install -r requirements.txt
python scraper.py
```

## Stretch goals
- Scrape multiple sites
- Schedule it daily with cron or GitHub Actions
- Keyword search and word-frequency analysis on saved headlines
